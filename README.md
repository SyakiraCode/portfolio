## About this site

A lightweight static site written in plain HTML, CSS and JavaScript, with no framework or build step. It is responsive, keyboard accessible and hosted on GitHub Pages.

```
├── index.html      # page content
├── styles.css      # layout and theme
├── script.js       # mobile menu and copy-email button
├── resume.pdf      # latest resume
└── assets/         # images
```

To run it locally, clone the repo and open `index.html` in a browser, or run `npx serve .`
